# Inventory Management System

A small Python command-line project that checks product availability, validates a sale, and updates the inventory.

## Run the project

Make sure Python 3 is installed, then run:

```bash
python invent_system.py
```

The program displays the current inventory, asks for a product, checks its stock level, and updates the quantity after a sale.

## Concepts practiced

- Functions
- Dictionaries
- Conditional statements
- User input validation
- Exception handling
